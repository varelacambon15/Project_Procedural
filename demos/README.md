# Demos iniciales

Prototipos de un solo archivo, hechos antes de montar el proyecto. Se conservan como referencia.

- `sector-vacio.html`: FPS de ejemplo con niveles procedurales (salas y pasillos), drones, minimapa y mando.
- `banco-de-chatarra-v1.html`: primera versión del generador de pistolas modulares (piezas de Quaternius embebidas).

Están pensadas para publicarse como Artifact (sin `<html>`/`<head>`): cargan Three.js r128 desde cdnjs.
